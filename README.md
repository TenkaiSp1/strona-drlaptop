# drLAPTOP – modernizacja strony i pozycjonowanie

Projekt poprawy strony [drlaptop.pl](https://drlaptop.pl/) (WordPress + Elementor): szybkość na telefonie, SEO lokalne (Gdynia / Trójmiasto), widoczność w Google AI Overviews i ChatGPT, serwis wysyłkowy z kurierem.

**Zasada nr 1:** nie budujemy strony od nowa i nie zmieniamy adresów istniejących podstron. Jeśli coś usuwamy, ustawiamy przekierowanie 301.

## Zawartość
| Ścieżka | Co to jest |
|---|---|
| `prototyp/` | Klikalny prototyp: strona główna, cennik, zamów kuriera, laptopy gamingowe, podstrony 8 marek (ASUS, Apple, Lenovo, MSI, Dell, HP, Acer, Samsung). Otwórz `prototyp/index.html` w przeglądarce. Przełącznik „Notatki SEO” na górze. |
| `docs/audyt.md` | Audyt obecnej strony (stan z 05.11.2026) |
| `docs/konkurencja.md` | Porównanie z serwisgdynia.pl i dobryserwis.eu |
| `docs/plan.md` | Plan działań etapami, z checklistą |
| `docs/drlaptop-podsumowanie.xlsx` | Krótkie podsumowanie: speed test, plan na 30 dni, co Piotrek może zrobić od razu (do wspólnego pliku na Proton Drive) |
| `docs/pagespeed.md` | Poprawki szybkości na podstawie raportu PageSpeed |
| `PageSpeed Insights.html` | Zapisany raport PageSpeed (telefon 68, komputer 84) |
| `seo/schema-localbusiness.html` | Dane strukturalne do wklejenia (np. WPCode) |
| `seo/tytuly-opisy.md` | Tytuły, opisy i H1 dla wszystkich 39 podstron + 5 nowych |
| `seo/marki/` | Nowa treść 8 podstron marek: ASUS, Apple, Lenovo, MSI, Dell, HP, Acer, Samsung |
| `seo/nowe/` | Treść 3 nowych podstron: cennik, zamów kuriera, laptopy gamingowe |
| `seo/marki/_wspolne-sekcje.md` | Sekcje wspólne dla wszystkich marek (szablony globalne Elementora) |
